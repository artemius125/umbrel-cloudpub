CloudPub

Публикация локальных веб-приложений через HTTPS.

  1. В Umbrel откройте настройки CloudPub → Advanced → Environment variables.
  2. Задайте TOKEN и адреса в HTTP или HTTPS через запятую.
  3. Откройте кабинет CloudPub, чтобы увидеть публикации и подключить свой домен.
