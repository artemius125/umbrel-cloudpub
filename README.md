# CloudPub для Umbrel

Community App Store с приложением CloudPub для umbrelOS 2.0.1 на x86-64.
В этот же репозиторий можно добавлять другие приложения. ID каждого приложения
начинается с `artem-` и совпадает с именем его папки.

## Установка

Разместите репозиторий на Git-сервере, откуда Umbrel может клонировать его по
HTTP(S). В Umbrel откройте App Store → Community App Stores, добавьте URL
репозитория и установите CloudPub из магазина «Приложения Артёма».

В настройках CloudPub откройте **Advanced → Environment variables**.

- `TOKEN` — токен из личного кабинета CloudPub. Вводите его только в настройках
  на Umbrel и держите эти настройки закрытыми для посторонних.
- `HTTP` — список адресов локальных HTTP-сервисов через запятую без пробелов.
  Например, `192.0.2.10:8080,192.0.2.10:3000`.
- `HTTPS` — такой же список для сервисов с HTTPS на стороне локального приложения.
  Для HTTP-сервисов CloudPub сам предоставляет внешний HTTPS.

Используйте адреса, доступные контейнеру по сети. Для приложения на Umbrel
подойдёт IP Umbrel с портом сервиса, если этот порт доступен из контейнера.
После сохранения проверьте публикации в кабинете CloudPub и журнал агента в Umbrel.

Агент хранит конфигурацию в каталоге данных приложения. При удалении одного адреса
из списка также удалите соответствующую публикацию в кабинете CloudPub.
CloudPub запускает все публикации, ранее зарегистрированные этим агентом.
Если требуется опубликовать закрытое приложение, проверьте правила доступа к нему
перед передачей внешней ссылки.

Свой домен привязывается к публикации в кабинете CloudPub. Для облачного CloudPub
эта возможность доступна на тарифе PRO. Добавьте DNS-записи, которые покажет
кабинет, и дождитесь автоматического выпуска сертификата.

- [Запуск CloudPub в Docker](https://cloudpub.ru/docs/docker)
- [Подключение своего домена](https://cloudpub.ru/docs/domains)
- [Шаблон Umbrel Community App Store](https://github.com/getumbrel/umbrel-community-app-store)

## Тестовая страница

В магазине также есть приложение **Тест CloudPub**. Чтобы проверить туннель,
установите его и укажите `artem-cloudpub-demo:8080` в поле `HTTP` приложения
CloudPub. По внешней ссылке откроется статическая страница.
